  • Why 1 − H(p)? Every bit, the noise source flips a coin that lands “flip” with chance p. The receiver can't tell which bits it flipped — that coin's entropy, H(p), is exactly what each bit loses. (It's the curve from Guess the Coin's Entropy, upside down.)
  • Shannon's own example (§12): 1 error in 100 at 1,000 bits per second leaves 919 bits per second of information — not 990, because nobody knows which bits are wrong.
  • Hamming's code is the one Shannon prints in §17: X1, X2, X4 make three parity checks α, β, γ even; after the channel, the checks that come out odd spell, in binary, the position of the flipped bit.
  • Compress swaps the 5-bit code for a Huffman code built from English letter frequencies: bits per letter instead of 5. Squeezed text has no slack — one flipped bit can derail every letter after it.
What is this?
  • Fig. 1 of Shannon's 1948 paper: every communication system — telegraph, telephone, radio, the internet — is these five boxes plus a noise source.
  • The transmitter can compress (squeeze out the message's own redundancy) and protect (add redundancy the receiver can check).
